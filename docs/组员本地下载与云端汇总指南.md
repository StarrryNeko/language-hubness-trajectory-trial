# 两名组员使用 Windows 下载并上传权重

> 两人在 Windows 上并行下载五个必跑模型；Moonlight 暂不下载。

## 1. 分工

| 组员 | 模型 | 预计合计 |
|---|---|---:|
| A | Qwen2.5-1.5B、BLOOM-1.7B、XGLM-1.7B、Llama-3.2-3B | 约16–17GB |
| B | Llama-3.1-8B | 约16GB |

- A需申请：`https://huggingface.co/meta-llama/Llama-3.2-3B`
- B需申请：`https://huggingface.co/meta-llama/Llama-3.1-8B`
- 两人使用各自获得许可的 Hugging Face 账号，不共享token。

## 2. 两人共同准备

在 **Anaconda Prompt或PowerShell** 中执行：

```powershell
git clone <项目仓库URL>
cd language-hubness-trajectory

conda create -n langhub python=3.11 -y
conda activate langhub
python -m pip install --upgrade pip
python -m pip install "huggingface_hub>=0.24"
```

如果使用项目压缩包，解压后进入含有`src`和`configs`的根目录即可。

设置缓存和超时；可把`D:`换成空间充足的盘符：

```powershell
$env:HF_HOME="D:\langhub_hf_cache"
$env:HF_HUB_CACHE="D:\langhub_hf_cache\hub"
$env:HF_HUB_DOWNLOAD_TIMEOUT="600"
$env:HF_HUB_ETAG_TIMEOUT="60"
$env:HF_HUB_DISABLE_XET="1"
```

这些变量仅对当前窗口生效。重新打开PowerShell后需要再次设置。建议保留至少40GB可用空间。

登录并核对账号：

```powershell
hf auth login
hf auth whoami
```

## 3. 组员A：下载并验证四个模型

```powershell
$outputRoot = "D:\langhub_models_A"
$models = @(
  "Qwen/Qwen2.5-1.5B",
  "bigscience/bloom-1b7",
  "facebook/xglm-1.7B",
  "meta-llama/Llama-3.2-3B"
)

foreach ($model in $models) {
  python src/download_model_weights.py `
    --suite configs/model_suite_week1_required_random200.json `
    --model $model `
    --output-root $outputRoot
  if ($LASTEXITCODE -ne 0) { throw "下载失败：$model；保持目录并重跑本段命令" }

  python src/download_model_weights.py `
    --suite configs/model_suite_week1_required_random200.json `
    --model $model `
    --verify-root $outputRoot
  if ($LASTEXITCODE -ne 0) { throw "验证失败：$model" }
}
```

## 4. 组员B：下载并验证Llama-3.1-8B

```powershell
$outputRoot = "D:\langhub_models_B"
$model = "meta-llama/Llama-3.1-8B"

python src/download_model_weights.py `
  --suite configs/model_suite_week1_required_random200.json `
  --model $model `
  --output-root $outputRoot
if ($LASTEXITCODE -ne 0) { throw "下载失败；保持目录并重跑本段命令" }

python src/download_model_weights.py `
  --suite configs/model_suite_week1_required_random200.json `
  --model $model `
  --verify-root $outputRoot
if ($LASTEXITCODE -ne 0) { throw "验证失败：$model" }
```

下载中断时不要删除目标目录；重新运行原命令会尝试续传。验证成功时应显示`PORTABLE_MODEL_ROOT_VERIFIED`。

## 5. 使用WinSCP上传

云端统一目标目录：

```text
/root/autodl-tmp/models/
```

组员A从`D:\langhub_models_A`上传以下四个文件夹：

```text
Qwen__Qwen2.5-1.5B
bigscience__bloom-1b7
facebook__xglm-1.7B
meta-llama__Llama-3.2-3B
```

组员B从`D:\langhub_models_B`上传：

```text
meta-llama__Llama-3.1-8B
```

只上传模型文件夹，不上传token、`langhub_hf_cache`、外层`langhub_models_A/B`或`portable_models_manifest.json`。

正确结果：

```text
/root/autodl-tmp/models/Qwen__Qwen2.5-1.5B/config.json
```

不要形成：

```text
/root/autodl-tmp/models/langhub_models_A/Qwen__Qwen2.5-1.5B/config.json
```

`.safetensors`几乎不可压缩，直接使用WinSCP/SFTP断点上传即可。

## 6. 云端最终验收

五个文件夹到齐后，在云端终端执行：

```bash
cd /root/autodl-tmp/language-hubness-trajectory
conda activate langhub
export LHT_MODEL_ROOT=/root/autodl-tmp/models

python src/download_model_weights.py \
  --suite configs/model_suite_week1_required_random200.json \
  --verify-root "$LHT_MODEL_ROOT"
```

确认五个模型均显示`Verified`且最终出现`PORTABLE_MODEL_ROOT_VERIFIED`，再启用离线模式并审计Qwen：

```bash
export HF_HUB_OFFLINE=1
export TRANSFORMERS_OFFLINE=1
mkdir -p audits

python src/audit_model_runtime.py \
  --suite configs/model_suite_week1_required_random200.json \
  --model Qwen/Qwen2.5-1.5B \
  --sentences 10 \
  --output audits/qwen_smoke.json
```

Qwen通过后，再审计全部五个模型：

```bash
python src/audit_model_runtime.py \
  --suite configs/model_suite_week1_required_random200.json \
  --sentences 10 \
  --continue-on-error \
  --output audits/required_models.json
```

常见错误：`401/403`表示账号或Llama许可有问题；缺少`config.json`通常表示下载不完整或上传时多套了一层目录。
