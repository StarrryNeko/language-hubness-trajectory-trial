# Mean-pooling 正式实验操作与验证清单

## 协议

- [ ] `metrics.representations` 严格等于 `["mean_pool"]`。
- [ ] `metrics.primary_representation` 严格等于 `mean_pool`。
- [ ] extraction manifest 的协议版本为 `mean_pool_v1`。
- [ ] 句子编码使用原始文本 token；可选 BOS 不进入均值。
- [ ] 每个语义 ID 包含配置要求的全部语言且恰好一条句子。
- [ ] 所有相似度候选均限制在同一语义 ID 内。

## 隐藏状态

- [ ] 只生成 `hidden/sentence_layer_mean_pool.npy`。
- [ ] 数组形状为 `[句子数, 层数, hidden_dim]`。
- [ ] metadata 与数组第一维严格对齐。
- [ ] 数组没有 NaN、Inf、零范数行或截断输入。
- [ ] FP32 强制模型继续使用 FP32 计算与存储。

## Hubness 与机制

- [ ] 同时报告 reverse-kNN、centrality、rank percentile、medoid rate。
- [ ] 检查来源语言广度、语言系与文字系统覆盖。
- [ ] raw cosine 与 local-scaled cosine 在同层比较。
- [ ] 完成 k=1/3/5/10 敏感性分析。
- [ ] 范数、全局质心、留一语义质心、PC1 和局部密度只作为机制指标。
- [ ] 正式结论要求连续层、多模型与独立 seed 复现。

## 行为关联

- [ ] 提示编码不自动加入 tokenizer special tokens。
- [ ] 解码阶段屏蔽 tokenizer 的全部 special token ID。
- [ ] 每条生成达到冻结的 token budget，并在写盘前通过 token 审计。
- [ ] manifest 记录 plain-text prompt、special-token suppression 和零违规计数。
- [ ] 参考语言门禁只使用 fastText top-1 标签正确率，不使用置信度阈值。
- [ ] 输出侧 retention/leakage 使用冻结的 fastText 置信度阈值。
- [ ] 阈值扫描只允许读取独立校准集及其 manifest；正式参考集禁止阈值扫描。
- [ ] 校准 manifest 证明两个 seed 来源哈希、363 个校准 ID 和与 208 个正式 ID 零重叠。
- [ ] `english_span_threshold=0.15` 保持结果揭示前冻结，不使用正式结果调参。
- [ ] 空输出率和参考语言 top-1 识别率通过预注册门槛。
- [ ] 行为关联只作观察性结论，不作激活层面的因果表述。

## 运行后

- [ ] `python -m compileall config src scripts tests` 通过。
- [ ] 全部单元测试通过。
- [ ] `rg` 确认仓库不包含已移除表示方法的实现或协议字段。
- [ ] 旧协议结果单独归档，不与 `mean_pool_v1` 或新行为生成结果混用。
