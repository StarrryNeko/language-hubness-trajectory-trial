# 验证输出说明

当前协议只提取 `mean_pool`，模型输入末尾不追加 EOS，也不生成任何 EOS 表示或表示一致性结果。

运行：

```bash
python src/run_pilot.py --config configs/qwen25_1_5b_mvp.json
```

验证结果保存在 `outputs/<experiment>/validation/`：

| 文件 | 验证问题 | 主要判定依据 |
| --- | --- | --- |
| `01_dataset.md/json` | 平行数据是否完整 | 至少 20 种语言、语义组完整、每组每语言一条 |
| `02_representations.md/json` | mean-pool 是否可用 | 三维 shape、metadata 对齐、全数组有限值、无截断 |
| `03_semantic_scope.md/json` | 是否严格同语义比较 | 不计算跨语义相似度，bootstrap 单位为 semantic ID |
| `04_hubness_evidence.md/json` | 英语主证据是否成立 | 四项 CI 下界在同层为正，并与来源广度在同层连续成立 |
| `05_tie_geometry.md/json` | top-k 是否受边界并列主导 | fractional tie 权重与高并列层 |
| `06_density_control.md/json` | 结论是否为局部密度产物 | 主条件、来源广度和 local-scaled 证据在同层重合 |
| `07_k_robustness.md/json` | 结论是否依赖 k | 多个 k 下联合连续区间是否一致 |
| `validation_summary.md/json` | 单模型最终状态 | `INVALID`、`NOT_SUPPORTED`、`DENSITY_SENSITIVE` 或 `ROBUST` |

## 单模型状态

- `INVALID`：文件缺失、数组含 NaN/Inf、证据网格不完整或其他结构验证失败。
- `NOT_SUPPORTED`：四指标联合证据与来源广度的同层连续区间不足。
- `DENSITY_SENSITIVE`：主条件通过，但与 local-scaled 证据的同层重合区间不足。
- `ROBUST`：主条件、来源广度和局部密度控制在相同连续层达到预设阈值。

## 查看 hidden-state 对应句子

```bash
python src/inspect_hidden_states.py \
  --config configs/qwen25_1_5b_mvp.json \
  --rows 0,1,2 \
  --layers 0,16,28 \
  --representations mean_pool \
  --show-token-sequence
```

该命令显示原句、实际输入 token 以及所选层向量的 norm、均值、标准差和前若干维。
